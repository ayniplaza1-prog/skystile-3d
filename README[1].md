# Шаҳрофар — интерактивное 3D-демо

Интерактивный 3D-сайт для жилого комплекса «Шаҳрофар» (г. Бохтар): 3 блока (А, Б, В)
по 14 этажей. Пользователь вращает здание, наводит на этаж (видно, сколько
квартир свободно), нажимает на этаж и видит список квартир с площадью,
ценой и статусом (свободна / бронь / продана).

Сделано на **Three.js** (без сборки, библиотека подключается с CDN).

## Файлы

- `index.html` — разметка, стили и интерфейс (легенда, панель, фильтры)
- `app.js` — 3D-сцена: здания, свет, управление, клики по этажам
- `data.js` — данные о блоках, этажах и квартирах (площади из альбома)

## Как запустить локально

Нужен любой локальный сервер (просто открыть файл через `file://` не даст ES-модулям работать):

```bash
# вариант 1 — Python
python3 -m http.server 8080
# вариант 2 — Node
npx serve .
```

Затем откройте http://localhost:8080

## Как выложить на GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub (например `shahrofar-3d`).
2. Загрузите туда эти файлы (`index.html`, `app.js`, `data.js`).
3. Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/root`.
4. Через минуту сайт будет доступен по адресу `https://ваш-логин.github.io/shahrofar-3d/`.

Библиотека Three.js загружается с CDN — сборка (npm/vite) не нужна.

## Что можно доработать дальше

- **Реальная модель:** сейчас здания — процедурные «коробки». Можно
  смоделировать дом в Blender по вашим чертежам и экспортировать в `.glb`,
  затем загружать через `GLTFLoader`.
- **Планы квартир:** добавить в карточку квартиры изображение плана
  (у вас уже есть 3D-рендеры).
- **Прогулка внутри:** вторая камера от первого лица + WASD.
- **Реальные статусы/цены:** сейчас демонстрационные, правьте в `data.js`.
